## 一、对参考论文范式的理解（重要）

类 "Analytical dataset to determine squeezing potential of deep tunnels"（如 Hoek-Marinos squeezing chart、近期 ML 改造版本）这类论文的**共同套路**：

1. **构建一个高质量、可公开的"案例库 / 分析数据集"**（这是论文的核心资产）
2. 在数据集上提出/比较若干**判别准则**（经验公式、阈值、ML 模型）
3. 用统计指标证明新方法相比经典经验准则的优势
4. **可解释性 + 简洁阈值图**：给出工程师能直接用的判别图

→ 对我们：**"红阳矿区微震大能量/危险事件分析数据集 + 多准则对比判别框架"**，
天然适合做成一篇 **"数据 + 方法"双重贡献** 的论文（这类论文比纯方法论文更容易接收，且引用率高）。

## 二、问题定义（精确说人话）

**输入**：一次微震事件（或事件序列窗口）的特征
**输出**：该事件是否属于"危险/大能量事件"（二分类）或危险等级（多级）

**关键决策 — "什么算危险"的标签定义**（论文成败在此）：

| 候选标签 | 含义 | 优缺点 |
|---------|------|--------|
| L1 能量阈值 | E ≥ 10^x J | 简单客观，但物理上"大能量 ≠ 危险" |
| L2 W/y 值超阈 | 现有物理判据触发 | 与项目一致，可直接对标 |
| L3 是否前兆 | 事件后 T 小时内发生大能量/冲击 | 真正"危险" — 最有学术价值 |
| L4 专家标注 | 现场记录的预警/响应 | 高质量但稀缺 |

**推荐组合**：以 **L3（前兆判别）为主标签**，L1/L2 作为辅助参考。即：
> "判别一次微震事件是否是后续大能量冲击的前兆"

这一定义可让论文标题直接写成：
**"A microseismic precursor analytical dataset and machine-learning identification framework for rockburst hazard in the Hongyang coal mine"**

## 三、可发表的 Idea 清单（按推荐度排序）

### ★★★ Idea A：物理-数据混合判别（Physics-Informed ML）— 最推荐

**核心**：把现有 W/y 物理判据作为**先验特征 / 软约束**注入 ML 模型，而不是替代它。

**做法**：
- 特征 = [微震事件统计特征] ⊕ [现有 W 值] ⊕ [W 物理参数（σ, E, λ, φ 等）]
- 模型 = XGBoost / LightGBM（可解释性强）+ SHAP 分析
- 对比基线：
  1. 纯 W 阈值法（你们现在用的）
  2. 纯数据驱动 ML（无 W 特征）
  3. **W + ML 混合（本方法）** ← 创新点

**论文亮点**：
- 既保留物理可解释性（领域专家能接受），又拿到 ML 的精度
- SHAP 分析可量化 "W 准则在哪些工况失效，ML 在哪些工况补足"
- 直接对标项目现有工具，论文与工程闭环

**为什么推荐**：你们已经有 W 物理判据 + 微震数据，**这两样合起来在国内冲击地压领域是稀缺组合**，纯 ML 论文一抓一把，物理-数据混合论文有差异化。

---

### ★★★ Idea B：时空前兆模式挖掘 — 论文故事性最强

**核心**：不是判别单个事件，而是判别**事件序列**是否进入"危险模式"。

**特征工程**（参考夏永学2010 五指标 + 拓展）：
- b 值变化（震级-频度斜率，下降是前兆）
- 能量指数 EI、视应力 σ_app
- 事件迁移速度（震源向工作面/断层迁移）
- 时空聚类密度（DBSCAN / ST-DBSCAN）
- A(b)、S 值（单日能量比）
- **新增**：图神经网络刻画事件时空关联（用 GNN 是论文加分点）

**模型**：滑动时间窗 + LSTM / Transformer / Temporal GNN

**论文亮点**：把"单事件分类"提升为"时空模式识别"，研究层次更高。

---

### ★★ Idea C：不平衡学习与不确定性量化

**痛点**：危险事件天然稀少（典型 < 5%），常规 ML 会"全预测为安全"也能拿 95% 准确率。

**做法**：
- 重采样：SMOTE / ADASYN
- 代价敏感学习 / Focal Loss
- 异常检测视角：Isolation Forest / One-Class SVM / Autoencoder reconstruction error
- **不确定性量化**：Conformal Prediction 给出"危险事件 + 90% 置信区间"
  → 直接对应工程上"分级预警"

**论文亮点**：方法新颖（保形预测在冲击地压领域少见），且工程上有实用价值（误报/漏报可控）。

---

### ★★ Idea D：W 判据的数据驱动重标定

**核心**：现有 W 公式有一堆固定参数（σ=5400, E=2580000, k=0.58, ξ=0.28...），这些是经验值。用历史数据**反演最优参数**或**逐工作面自适应参数**。

**做法**：
- 贝叶斯参数估计 / 遗传算法优化 W 公式参数
- 比较"通用 W"与"红阳矿区专属 W"的判别能力
- 衍生：对每个工作面给出专属判据图

**论文亮点**：与现场工具直接关联，结果可直接上系统；偏工程导向，适合中文核心。

---

### ★ Idea E：可视化决策图（"分析数据集"经典玩法）

**核心**：照搬 Hoek squeezing chart 范式 — 在二维/三维特征空间画**分区判别图**。

例如：横轴 = 能量对数，纵轴 = b 值，颜色 = 危险概率 → 一张图工程师就能查。

**做法**：t-SNE/UMAP 降维 + 决策边界可视化 + 直接嵌入到现有 page5/page6。

**论文亮点**：作为主论文（A 或 B）的配套**应用篇 / 工程篇**，中文期刊容易出。

## 五、分析数据集（论文核心资产）规划

参考"Analytical dataset"范式，规划如下：

### 5.1 命名
**HMRP-2026**（Hongyang Microseismic Rockburst Precursor dataset, 2026）

### 5.2 字段（每条记录）
- **事件基本信息**：时间戳、震源 XYZ、能量 E、震级 M、定位精度
- **空间上下文**：到最近断层距离、到工作面距离、所在分层
- **时间上下文**（前后窗口）：前 24h/72h 事件计数、累积能量、b 值
- **物理判据**：W 值、各物理参数快照
- **工程参数**：当日推进度、开采深度、回采阶段
- **标签**：
  - y1：是否大能量（E ≥ 阈值）
  - y2：未来 T 小时内是否发生大能量（前兆标签）
  - y3：现场实际预警/处置等级

### 5.3 数据来源
- 主数据：`1208微震事件（清洗后）.xlsx`
- 工程图：`红阳三矿采掘工程图10.28.dxf`（已有 dxf 解析脚本 `database/inspect_dxf.py`）
- 物理参数：`资料/数据源/红阳矿区微震预警判据.xls`

### 5.4 配套发布
- 数据集 + 数据说明（Data Descriptor 风格）
- 基线代码 + 评测脚本（GitHub）
- 论文里把"数据集本身"作为一个贡献点

## 九、需要你确认的方向（4 个关键决策）

1. **"危险"标签如何定义** — L1（能量阈值）/ L2（W 触发）/ **L3（前兆）** / L4（专家标注）？
   - 我倾向 L3，论文价值最高，但需要确认数据里能不能定义"前兆窗口"
2. **主攻 Idea** — A / B / C / D / E？建议 A + E 组合
3. **论文目标层级** — SCI / EI / 中文核心？决定数据集规模和实验密度
4. **数据集是否开源** — 开源能让论文价值翻倍（Data Descriptor 类期刊），但需现场许可
